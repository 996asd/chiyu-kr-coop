## 一、v2.3.1 核心功能亮点

- **三标签极简大厅：「樱花联机」 | 「局域网」 | 「公网服务器」**
  - **樱花联机（默认页，异地免费开黑首选）**：
    - **仅房主需要，队友完全不用装、不用注册！**
    - **免密钥自动感知**：房主在官方 SakuraFrp 启动器启动 TCP `17777` 隧道后，游戏战桌自动抓取地址，一点即复制发给队友（绝不读取官方 `config.json` 密钥）。
    - **游戏内一键下载安装官方樱花 + 4 步新手向导**：没装过、没注册过樱花也没关系！点 **`樱花助手`** 可直接从官方接口下载最新 `SakuraLauncher.exe`（自动 MD5 校验），按 4 步卡片直达注册、实名、复制访问密钥一键登录、按实时低负载选节点一键建好 TCP `17777` 隧道（自动关闭 HTTPS，支持「公开直播合规仅多线」筛选与翻页）。
    - **三线自动并发测速（默认 / 电信 `dx.` / 移动 `yd.`）+ 免费 P2P 优先自动回退**：队友复制整行樱花日志点 **`粘贴`**，自动提取地址并并发测速选中最低延迟线路；若房主开启了端口导出 P2P，2.6 秒不通自动无缝切回樱花中继。
    - **主播防窥打码**：开启「防窥:开」后界面自动隐藏樱花域名与端口，点复制依然复制完整地址，直播不怕撞房。
    - **直连双层断线保局（零中继服也能防掉线！）**：
      - 一层 **180 秒无感热续传**：樱花节点瞬断或网络抖动时自动暂停保局，恢复后 0.2 秒原地续传零重载；
      - 二层 **2P 闪退高速追帧重连**：2P 游戏意外崩溃重启后，首页顶部一键高速追帧接回对局。
    - **局内实时切缓冲（`100ms / 150ms / 200ms / 300ms`）+ 不断线返回战桌换关**：打完或翻车点「返回战桌」不断线秒换地图与英雄！
- **内置实时语音连麦（零外部软件，直播效果拉满）**
  - 纯 LuaJIT FFI + Windows WinMM 独立线程（16kHz + IMA-ADPCM），高延迟/樱花链路自动启用 80ms 双帧低包频打包（语音包频减半更稳），拥塞时自动让路给 60Hz 帧同步，绝不拖慢游戏。
  - 支持 **`按V说话`**（默认防啸叫）/ **`自由麦`** / **`已闭麦`**（`M` 键一键闭麦），自带房间试麦、声波特效与战斗语音气泡。
- **全系列双人合作守关（2P Co-op）**
  - **全部 201 关**、**全部 105 位英雄**、**59 选 12 自由混搭塔池**、**全 4 档难度（含「不可能」）**。
  - 双英雄各自独立大招（`A`/`S`）+ 独立冷却援军；支持独立 50/50 经济（局内点 `转50` 或右键/Shift 左键快速转 `200` 金）或共享金库；支持红蓝塔位保护或自由共享。
- **公网中继服模式（多房大厅 / 4 位房间码 / 5 分钟追帧重连）**
  - `full-and-server` 完整包内置零依赖 Go 单文件服务端（Windows / Linux），1 核 1G 即可带百房。

## 二、三种联机方式速览

### 方式 A：异地远程免费开黑（默认「樱花联机」页）
1. **1P 房主**：没装樱花就点底部 **`一键装樱花`** 或 **`樱花助手`** 跟着 4 步向导 2 分钟搞定；开好 TCP `17777` 隧道后点 **`创建樱花房间并备战`**，点绿条一键复制地址发微信/QQ 给朋友。
2. **2P 队友**：什么软件都不用装！复制房主发来的整段话（带汉字/时间也没事）→ 进大厅点右边 **`粘贴`** → 点 **`三线测速`** 自动挑最快线 → 点 **`立即直连房主战桌`** 秒进房！

### 方式 B：同宿舍 / 同 Wi-Fi 局域网（切到「局域网」页）
1. 1P 点 **`创建局域网房间`**（首次放行 Windows 防火墙）。
2. 2P 等 2 秒在下方「酒馆布告栏」点 **`揭榜加入`**（也可右侧输入局域网 IP 或点 `本机双开` 测试）。

### 方式 C：傻瓜式一键自建公网中继服（切到「公网服务器」页，适合主播水友多房大厅！）
- **零成本 · 游戏内一键开服（小白推荐）**：在「公网服务器」页点右上绿色 **`一键自建公网服`** → 点 **`一键启动本机服务器 (17780)`**（自动下载校验 `kr-mp-server.exe` 并无黑框启动、自动接入）→ 步骤 2 配合樱花一键映射 `17780` 把地址发群里，**所有水友免装樱花、免注册**直接进大厅互开房间！默认开启「退游戏保活」，房主游戏闪退也不炸水友房。
- **7×24 小时永久群服 · Linux 云服务器 1 行命令**：
  ```bash
  curl -fsSL https://gitee.com/chiyu-studio/chiyu-kr-coop/raw/main/tools/deploy_server.sh | sudo bash
  ```
  自动下载校验最新版 + 配置 `systemd` 开机自启 + 放行防火墙 `17780` 并打印可直接粘贴的 `公网IP:17780`（记得云控制台安全组放行 TCP `17780`）。

## 三、常用快捷键与局内操作

| 快捷键 / 按钮 | 作用 |
| --- | --- |
| `F10` | 打开 / 关闭联机大厅（内置 4 页新手教程与樱花助手） |
| `F9` | 显示 / 隐藏顶部联机信息条 |
| 按住 `V` / `M` | 按键说话（默认 `按V说话`） / 一键闭麦或恢复 |

| `A` / `S` | 1P / 2P 各自英雄大招 |
| `W` / `Space` | 双端同步提前出怪 / 双端同步暂停继续 |
| 顶栏 `转50`（右键/Shift 点转 200） | 独立经济给队友打钱救场 |
| 顶栏 `缓冲` / `1x` / `回桌` | 局内实时切缓冲档位 / 1x·2x 同步倍速 / 不断线返回战桌 |

## 四、无痕卸载与报错排查

- **无痕卸载**：双击补丁包里的 **`一键卸载联机补丁.bat`**（或删游戏目录 `kr_mp\`、恢复 `UH.lua.kr_mp_backup`、删桌面快捷方式），绝不损伤原版游戏与存档。
- **大厅热更新**：点大厅右上角 **`检查更新`** 可直接从 Gitee/GitHub 增量更新补丁文件，无需重新下载压缩包。
- **遇到报错或同步异常**：双击补丁包里的 **`一键收集报错包.bat`**，10 秒打包日志、每 30 帧哈希与 `复制给AI的提问词.txt`，可发给作者或配合 **[AI修复指南.md](./AI修复指南.md)** 交由 AI 排错；开发者规范见 **[AGENTS.md](./AGENTS.md)** 与 **[CONTRIBUTING.md](./CONTRIBUTING.md)**。
