    - `Alt + 鼠标左键`：地图打点标记（双方实时看到脉冲光环与提示）

- **双模式联机（一套补丁通吃）**
  - **局域网模式（LAN）**：同 Wi-Fi / 校园网 / 虚拟局域网（如 ZeroTier / Radmin VPN）下自动扫描发现房间，零配置开黑。

## 二、安装与卸载（30 秒搞定）

### 方式 1：Gitee 国内直连下载压缩包安装（推荐，免翻墙免登录）
1. 打开 Gitee 发行版页面：https://gitee.com/chiyu-studio/chiyu-kr-coop/releases ，下载最新版的 **`KR-MP-FL4.1.0-v1.2.0-client-patch.zip`**（约 170 KB；需要自建公网中继服可下 `full-and-server.zip`）。
2. 解压本补丁包到任意位置（不需要直接丢进游戏目录）。
3. 双击 **`一键安装联机补丁.bat`**。
4. 在弹出的文件夹选择窗口中，选中你的 **FL 4.1.0 游戏目录**（即包含 `Kingdom Rush FL_Alliance-FL4.1.0.exe` 的文件夹）。
5. 安装完成后，游戏目录会自动生成一个 **`启动联机版_FL4.1.0.bat`**（自动锁定 60 FPS 以确保帧同步一致）。
6. 以后双方都双击 **`启动联机版_FL4.1.0.bat`** 启动游戏，进入后点击左上角 **`联机大厅 (F10)`** 即可联机！

### 方式 2：直接从 Gitee 克隆源码安装（适合开发者 / 国内 AI 助手自动执行）
```powershell
git clone --depth 1 https://gitee.com/chiyu-studio/chiyu-kr-coop.git
powershell -ExecutionPolicy Bypass -File .\chiyu-kr-coop\tools\install_patch.ps1 -TargetDir "你的FL4.1.0游戏目录" -Silent
```

### 无痕卸载
- 双击补丁包里的 **`一键卸载联机补丁.bat`**，选择游戏目录即可彻底清理 `kr_mp/` 并恢复原有 `UH.lua`（如有）。

## 三、如何和朋友联机？

### 方式 A：局域网联机（同 Wi-Fi / 虚拟局域网）
1. 双方启动游戏，点击左上角 **`联机大厅 (F10)`**，停留在 **`局域网联机`** 标签页。
2. 1P（房主）点击 **`创建局域网房间（1P 房主 · 蓝方）`**。
3. 2P（队友）在下方「已发现的局域网房间」列表里点击 **`加入`**（若跨网段/使用虚拟局域网，可在「直连 IP」栏输入房主 IP 点 **`直连加入`**）。
4. 双方选好各自英雄，1P 选好关卡 / 卡组 / 经济与塔权规则，点击 **`开始双人合作守关！`**。

### 方式 B：樱花映射（SakuraFrp / OpenFrp）免费远程开黑（推荐，零费用！）

没有云服务器、又想和异地朋友开黑？用 **SakuraFrp（樱花映射）** 或 **OpenFrp** 免费 TCP 隧道即可，提供两种玩法：

1. **极速直连模式（30 秒开玩，不需要中继服）**：
   - 房主在樱花映射新建一条 **TCP 隧道**，本地 IP 填 `127.0.0.1`，**本地端口填 `17777`**，启动隧道，复制樱花给的连接地址（如 `cn-cd-dx-2.natfrp.cloud:54321`）发给朋友。
   - 房主进游戏打开联机大厅 → **`局域网联机`** 页 → 点 **`创建局域网房间`**，把下方规则里的 **`缓冲`** 切到 **`缓冲:樱花200ms`**（防止免费节点抖动卡顿）。
   - 2P 朋友复制房主发来的地址 → 在 **`局域网联机`** 页点 **`粘贴`** 按钮（自动清理多余文字与中文冒号）→ 点 **`直连加入`** 即可秒进！
2. **樱花映射 + 断线重连模式（强烈推荐，打长关不怕闪退！）**：
   - 房主先双击完整包里的 `server\启动公网中继服.bat`（监听本地 `17780`），在樱花映射新建 **TCP 隧道** 映射 **本地端口 `17780`**。
   - 房主和朋友都切到 **`公网服务器`** 页，点 **`粘贴`** 填入樱花地址并点 **`连接`**，即可同时拥有 **4 位房间码 + 5 分钟闪退/掉线一键高速追帧重连**！

### 方式 C：自建公网服务器联机（云服务器 / 固定公网 IP）
1. 双方切换到 **`公网服务器（大厅 / 房间码）`** 标签页，在「服务器」栏填写中继服地址（格式 `IP:17780` 或 `域名:17780`），点击 **`连接服务器`**。
2. 1P 可选填密码与「公开大厅 / 仅房间码」，点击 **`创建公网房间（1P 房主）`**，系统自动生成 4 位房间码（如 `#GKDG`）。
3. 2P 在公开列表中点 **`加入`**，或输入 4 位房间码（及密码）点 **`凭房间码进房`**。
4. **中途掉线/游戏闪退怎么办？**
   - 只要一方意外掉线，另一方界面会自动进入琥珀色 **`等待队友重连`** 冻结保局（默认保留 5 分钟）。
   - 掉线玩家重新打开游戏 → 打开联机大厅 → 切到公网服务器页 → 点击顶部亮橙色 **`一键重连上次对局`**，几秒钟高速追帧完成后双方自动无缝继续游戏！

## 四、自建公网中继服（给房主/群主，1 分钟部署）

完整包 `server/` 目录下已内置零依赖单文件 Go 服务端，极省资源（单台 1 核 1G 最低配云服务器可轻松承载上百个房间）：

- **Windows 服务器 / 本机端口映射**：直接双击 `server\启动公网中继服.bat`（默认监听 TCP `17780`，状态查询 `http://127.0.0.1:17781/health`）。
- **Linux 云服务器（Ubuntu / CentOS / Debian）**：
  ```bash
  chmod +x kr-mp-server-linux-amd64
  nohup ./kr-mp-server-linux-amd64 -addr :17780 -http :17781 -grace 300 > kr_mp_server.log 2>&1 &
  ```
- 记得在云服务器安全组 / 防火墙中**放行 TCP `17780` 端口**，把 `你的公网IP:17780` 发给好友即可。

## 六、常见问题排查

1. **提示「核心脚本哈希不一致」或「版本不匹配」**：说明双方使用的 FL 4.1.0 主程序文件或联机补丁版本不同（比如其中一人装了额外的修改脚本），请确保双方使用同一份 FL 4.1.0 原包与同一版本联机补丁。
2. **局域网搜索不到房间**：检查 Windows 防火墙是否放行了 `Kingdom Rush FL_Alliance-FL4.1.0.exe` 的专用网络通信（TCP `17777`、UDP `17778`），或直接手填房主局域网 IP 连接。
3. **如何确认双方完全同步？**：顶部信息条实时显示 `已校验: N` 与 `校验: 8位十六进制码`，每 30 帧自动核验双端全图单位、血量、金币与随机数状态；只要状态保持「联机中」即代表 100% 比特级同步。

## 七、用 AI 排错与参与群内/开源共建（GitHub + Gitee 双托管）

本项目内置完整的 **AI 友好协作工具链**，无论你是纯玩家还是会用 AI 编程工具（DeepSeek / ChatGPT / Claude / Cursor / Trae / Antigravity），都可以轻松上报问题或分享修复：

1. **遇到报错或某关不同步？**
   - 双击补丁包里的 **`一键收集报错包.bat`**，10 秒自动打包日志、每 30 帧哈希、本地文件体检报告，以及一份可直接复制的 **`复制给AI的提问词.txt`**。
   - 可以直接把诊断包丢进玩家群 / 仓库 Issue，或连同 **`AI修复指南.md`** 一起喂给 AI 自行定位修复！
2. **用 AI 修好 Bug 了，想分享给大家？**
   - **纯小白免注册方式**：双击 **`一键导出我的修改.bat`**，自动对比官方 `manifest.json`，只打包你改过的那几个 `.lua` 文件生成十几 KB 的 `KR-MP-群友修复补丁-*.zip`，丢到群里或 Issue 即可！
   - **开发者 / AI 编程工具方式**：阅读根目录的 **[AGENTS.md](./AGENTS.md)** 与 **[CONTRIBUTING.md](./CONTRIBUTING.md)**，直接在 GitHub 或 Gitee 仓库提 Pull Request（仓库内置 CI 自动做 Go/Lua 语法与文件防泄漏体检）。
3. **大厅一键检查更新**：
   - 打开联机大厅后，右上角自带 **`检查更新`** 按钮（后台原生异步检测，不卡游戏、不闪黑框；发现新版本会自动变绿提示并可一键打开下载页）。
