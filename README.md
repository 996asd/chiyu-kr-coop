## 三、三种联机方式详解

### 方式 A：同 Wi-Fi / 宿舍局域网（零配置）
1. 双方启动游戏 → 点 **`联机大厅 (F10)`**（默认在「局域网 / 樱花直连」页）。
2. 1P（房主）点 **`创建房间并备战`**（首次弹出防火墙提示请点「允许访问」）。
3. 2P（队友）在下方「酒馆布告栏」点 **`揭榜加入`**（跨网段或虚拟局域网也可在右侧直连框填房主 IP 加入）。
4. 双方选好英雄、1P 选好关卡/难度/卡组，点绿色 **`出征守关！`**。

### 方式 B：樱花映射（SakuraFrp / OpenFrp）免费异地远程开黑
1. **极速直连（30 秒开玩，无需中继服）**：
   - 房主在樱花映射新建 **TCP 隧道**，本地 IP 填 `127.0.0.1`，**本地端口填 `17777`**，启动后把地址发给朋友。
   - 房主建房后把房间顶部「缓冲」切到 **`缓冲:樱花200ms`**。
   - 朋友复制整行地址 → 点右侧 **`粘贴`**（自动清理多余文字与中文冒号）→ 点 **`立即直连队友战桌`**！
2. **樱花映射 + 5 分钟断线追帧重连（打长关强推）**：
   - 房主先双击完整包里的 `server\启动公网中继服.bat`（监听 `17780`），在樱花映射新建 **TCP 隧道** 映射 **本地端口 `17780`**。
   - 双方切到 **`公网中继服`** 页，点 **`粘贴`** 填入樱花地址并连接，即可畅享 4 位房间码 + 内置连麦 + 5 分钟断线追帧重连！

### 方式 C：自建公网中继服（云服务器 / 固定公网 IP）
完整包 `server/` 目录内置零依赖 Go 单文件服务端（1 核 1G 最低配即可带百房）：
- **Windows**：双击 `server\启动公网中继服.bat`（监听 TCP `17780`，状态监控 `:17781/health`）。
- **Linux VPS**：
  ```bash
  chmod +x kr-mp-server-linux-amd64
  nohup ./kr-mp-server-linux-amd64 -addr :17780 -http :17781 -grace 300 > kr_mp_server.log 2>&1 &
  ```
- 放行安全组/防火墙 **TCP `17780`** 后，双方在「公网中继服」页填入 `公网IP:17780` 连接即可。

## 五、常见问题排查与 AI 协作排错

1. **提示「版本不匹配」或「核心脚本哈希不一致」**：双方必须使用同一份 FL 8.2.0 原包与同一版本联机补丁（在大厅右上角点 **`检查更新`** 可一键下载最新版）。
2. **局域网搜索不到房间**：确认房主已点「创建房间」留在战桌内，且 Windows 防火墙放行了游戏主程序通信（TCP `17777`、UDP `17778`）。
3. **跨省/樱花联机略有卡顿**：房主在房间顶部将「缓冲」切至 **`樱花200ms`** 或 **`抗抖300ms`**。
4. **遇到报错或同步异常**：双击补丁包里的 **`一键收集报错包.bat`**，10 秒打包日志、每 30 帧哈希、本地文件体检报告及 **`复制给AI的提问词.txt`**，可发给作者或直接连同 **[AI修复指南.md](./AI修复指南.md)** 喂给 AI 定位修复；改完后双击 **`一键导出我的修改.bat`** 即可分享精简补丁包。开发者协作规范请见 **[AGENTS.md](./AGENTS.md)** 与 **[CONTRIBUTING.md](./CONTRIBUTING.md)**。
